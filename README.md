# Sree Home Foods

A responsive, traditional Telugu/Andhra-inspired storefront for Sree Home Foods.

## Included
- Telugu + English brand messaging
- Traditional Andhra visual direction
- Pickle, pachadi and podi product cards
- WhatsApp ordering flow
- Responsive mobile layout
- Family-story and trust sections
- GitHub Pages compatible static site

## Before launch
1. Replace the placeholder WhatsApp number `919999999999` in `index.html` with the business WhatsApp number.
2. Replace sample products/prices with the actual catalogue.
3. Add real product/family photographs when available.

## Deploy
Enable **Settings → Pages → Deploy from branch → main → /(root)** in GitHub.
